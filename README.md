# GAMBI·OS

Tâches, notes, habitudes, projets et finances dans une seule app.

**[Télécharger la dernière version](https://github.com/gambidrissi-dev/GAMBI_OS_MAC-Share/releases/latest/download/GambiOS.zip)** · macOS 14.0 ou plus récent

Ce dépôt ne contient pas de code : il distribue GAMBI·OS. L'app se met à jour toute seule
par [Sparkle](https://sparkle-project.org) depuis [`appcast.xml`](appcast.xml), et chaque archive est signée (EdDSA).

Toutes les apps, et **Vitrine** pour les installer d'un clic : https://apps-gambi.vercel.app/
